# pg-jsondiff

**JSON 結構對照**：路徑級新增／刪除／變更（不是行級文字 diff）。純前端。

也可當作 [Playgrounds（遊樂場）](https://samkuo.me/playgrounds/) 的 **Tool SAM**：掛上後左側載入授權的 `.json`，右側貼上要比對的內容。工具宣告在 `index.html` head。
